![](https://cdn.ldstatic.com/user_avatar/linux.do/laobaile/48/951224_2.png) 老白:

> 直接只改的读缓存的价格，没有通过倍率一键设置，所以没触发价格变动机制

在“渠道模型价格”弹窗里，直接手动改 prompt_cached_tokens 的价格并点击保存，那么会触发价格变动机制。原因是后端保存入口会：

校验并保存完整 ModelPrice；
调用 withPriceMultipliers 重新计算倍率，不依赖前端“一键倍率”；
用 existing.Price.Equals(input.Price) 比较完整价格对象；
如果价格变了，会生成新 reference_id / 新版本；
更新 channel updated_at、清理 API Key profiles、刷新 marketplace cache、重新 preload cachedModelPrices。

所以“没通过倍率一键设置，所以不会触发价格变动机制”这个因果关系本身是错的。倍率一键设置只是前端批量按供应商参考价生成价格的便捷操作，不是触发价格变动的唯一入口。
