#27 Fegg @Fegg 2026/5/14 22:03:53

这里我有一点小心得了，希望可以尽可能帮助到一点，直接上焚决：

  1. 基于 latex 写，用学校的 latex 模板，这样子可以避免 90% 以上的格式问题，剩下的无非就是图片大小、排版问题；

  2. 我用的是 codex 写的，推荐这几个 skill，个人高强度使用：
    2.1 论文写作：ml 相关的用 ml-paper-writing，其他的综合类的可以用 systems-paper-writing，这个skill之前帮你包圆写作部分。
    2.2 参考文献相关，使用 citation-management，找到的文献都高保真
    2.3 格式规范相关，用latex-thesis-zh，能帮你规范缩略语、表达一致、格式问题等
    以上这些skill用之前看看readme，有很多教程介绍

  3. 由于文章都是ai生成的，所以不用担心查重率，都很低，但是如果学校要检查ai率的话，用这套降ai的prompt，直接放到AGENTS.md里，要用的时候指出来让ai用。超好用的写作prompt库

  4. 画图的话，如果前期有实验的话那就正常画就好，没有的话我能想到的速成的就是用origin去描现成的图，这个在网上也有很多教程。drawio也很好使，用这个仓库直接将ai嵌入到drawio里画流程图事半功倍：https://github.com/DayuanJiang/next-ai-draw-io

  5. 直接多开，每个对话框写一章，不过这么干之前先brainstorm完，对齐一下颗粒度再这么干

#32 admin @passwd 2026/5/15 01:46:18

我想给点全面的建议, 不只是针对初稿:

论文内容方面:
首先建议佬友为你的claude code 安装这个ok-my-paper plugin, 用它来写论文的话ai率还是比较低的, 实测维普AIGC率测到大概是17%左右.
如果学校要求更低的AIGC率,就安装这个lessAI 来针对AIGC率高的段落进行改写.

评审老师最看重, 同时也最折磨人的是格式排版:
不要想着用skills一次性生成符合格式的docx文档! 因为后期你的论文内容洋洋洒洒几万字, 很容易撑爆ai的上下文窗口, 导致回复耗时且质量低, 出现各种幻觉, 然后成本还高.
我亲测过kimi-docx skill, 生成出来的文档中的目录, 引用上标, 字体, 段落间距方面都有巨多问题, 来来回回的修改不仅耗时, 更耗费你的心神.

故强烈建议佬友向私聊导师要一份模板, 或者一份往届毕业生的docx格式的论文, 然后你老老实实手动将内容逐段替换进去. “慢即是稳, 稳即是快”
