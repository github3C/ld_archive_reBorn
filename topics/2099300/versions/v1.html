食用教程

第一步：替换主程序

生成的激活码需要配合修改后的主程序才能用。

下载修改后的主程序：Snipaste.zip (2.7 MB)

把原来的 Snipaste.exe 备份后，用这个文件替换。

担心有病毒的佬友可以自己手动修改：

把下面的代码保存为 patch_snipaste.py，放到 Snipaste 安装目录下运行：

from __future__ import annotations

import hashlib
from pathlib import Path


INPUT_FILE = Path("Snipaste.exe")
PATCH_OFFSET = 0x33F217
ORIGINAL_BYTES = bytes.fromhex("8AC3")
PATCHED_BYTES = bytes.fromhex("B001")


def sha256(path: Path) -> str:
    h = hashlib.sha256()
    with path.open("rb") as f:
        for chunk in iter(lambda: f.read(1024 * 1024), b""):
            h.update(chunk)
    return h.hexdigest()


def patch_binary(input_path: Path) -> None:
    print(f"sha256(before): {sha256(input_path)}")
    
    data = bytearray(input_path.read_bytes())
    end = PATCH_OFFSET + len(PATCHED_BYTES)
    
    if end > len(data):
        raise SystemExit(
            f"file too small: need at least 0x{end:X} bytes, got 0x{len(data):X}"
        )

    current = bytes(data[PATCH_OFFSET:end])
    if current not in (ORIGINAL_BYTES, PATCHED_BYTES):
        raise SystemExit(
            "unexpected bytes at 0x{0:X}: got {1}, expected {2} or {3}".format(
                PATCH_OFFSET,
                current.hex(" ").upper(),
                ORIGINAL_BYTES.hex(" ").upper(),
                PATCHED_BYTES.hex(" ").upper(),
            )
        )

    if current == PATCHED_BYTES:
        print("already patched")
        return

    data[PATCH_OFFSET:end] = PATCHED_BYTES
    input_path.write_bytes(data)

    print(f"file  : {input_path}")
    print(f"offset: 0x{PATCH_OFFSET:X}")
    print(f"before: {current.hex(' ').upper()}")
    print(f"after : {PATCHED_BYTES.hex(' ').upper()}")
    print(f"sha256(after) : {sha256(input_path)}")
    print("patch success")


if __name__ == "__main__":
    patch_binary(INPUT_FILE)

运行：

python patch_snipaste.py

会直接修改 Snipaste.exe（建议先备份）。

第二步：获取机器信息

在需要激活的电脑上打开 PowerShell，运行这条命令：

powershell -Command "Write-Host 'MachineGuid:' (Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Cryptography').MachineGuid; Write-Host 'Workgroup:' (Get-CimInstance Win32_ComputerSystem).Workgroup"

会输出两行信息，复制下来：

MachineGuid: 26074b5f-d160-49fc-ae64-dba2857c9f47
Workgroup: WORKGROUP

第三步：生成激活码

打开生成器页面，把 MachineGuid 和 Workgroup 填进去，点生成就行。

第四步：激活

复制生成的激活码，在 Snipaste 里粘贴激活。

位置：托盘图标 → 解锁专业版 → 输入授权码 → 离线激活

说明

  • 激活码只对指定机器有效，换电脑要重新生成
  • 服务器不保存任何信息，只生成激活码
  • 修改后的主程序只改了 2 个字节（0x33F217 处：8A C3 → B0 01）

技术细节

分析的是 Snipaste 2.11.3 版本，主要涉及：

  • Blake2s 哈希（自定义 salt）
  • Ed25519 签名验证
  • 设备 ID 生成算法

激活码结构：0{checksum}-{base64(signature + xor(signature, license_json))}

详细的逆向过程会单独开帖记录，这里就不详细展开了。

注意： 纯技术研究用途，Snipaste 个人版也不贵，有条件建议支持正版。
